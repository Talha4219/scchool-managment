# **App Name**: Scholarly Central

## Core Features:

- Role-Based Authentication: Comprehensive login system with distinct dashboards and permissions for Admins, Teachers, Parents, and Students.
- Academic Directory: Centralized database for student admissions, registration records, and class/section assignments stored in the cloud.
- Attendance Engine: Daily attendance logging tool for teachers with immediate record accessibility for administrative reporting.
- Financial Suite: Generate automated fee vouchers and track payment statuses through an integrated ledger system.
- Performance Portfolio: Digital gradebook for exam result entry, historical record keeping, and result slip generation.
- AI Communication Assistant: A generative tool that analyzes student data to draft personalized progress notifications for parents.
- Alert Dashboard: Real-time UI component for managing and broadcasting important school-wide or class-specific notifications.

## Style Guidelines:

- Primary color: Sophisticated Deep Indigo (#364793) to convey authority, reliability, and academic tradition.
- Background color: Clean Porcelain White (#F7F8FA), maintaining high contrast and a sterile, organized institutional feel.
- Accent color: Vibrant Cobalt Blue (#4A6FE3) for interactive elements and primary call-to-action buttons.
- Font pairing: 'Alegreya' (Serif) for headlines to provide a literary and prestigious touch, combined with 'Inter' (Sans-serif) for body text and administrative data density.
- Line-art style icons with uniform stroke weights, representing tools, academics, and finances in a professional manner.
- A sidebar-centric navigation layout with clear content hierarchy, mimicking a modern ERP or CRM interface.
- Smooth, professional transition effects when switching between dashboard modules to emphasize efficiency.
